# Pixel Mentor - Database Schema (SQLite & SQLAlchemy)

## Overview
All persistent data is stored in a SQLite database file `pixel_mentor.db` managed through SQLAlchemy 2.0.

---

## Tables and Fields

### 1. `users`
Represents the anonymous user identified by `X-User-Id`.
- `id` (VARCHAR(64), Primary Key): UUID generated by the browser.
- `created_at` (DATETIME, default utcnow): First time seen.
- `category` (VARCHAR(32), default 'student'): 'student' | 'professional' | 'gig_worker'.
- `income_type` (VARCHAR(32), default 'monthly'): 'monthly' | 'irregular' | 'stipend'.
- `monthly_income` (FLOAT, default 0.0): Estimated monthly income in INR.
- `fixed_expenses` (FLOAT, default 0.0): Rent, EMI, fees, subscriptions in INR.
- `personality` (VARCHAR(64), default 'Safe Saver'): Assigned money personality (e.g. 'Safe Saver', 'Impulsive Spender', 'FOMO Investor', 'Calculated Builder').
- `onboarding_completed` (BOOLEAN, default False): Whether initial onboarding was completed.
- `mentor_notes` (TEXT, default ''): Running summary for mentor memory.

### 2. `expenses`
Logs individual expenses submitted by the user.
- `id` (INTEGER, Primary Key, Autoincrement)
- `user_id` (VARCHAR(64), ForeignKey('users.id'), Index)
- `amount` (FLOAT, Not Null): INR amount.
- `category` (VARCHAR(64), Not Null): e.g., 'Food', 'Transport', 'Entertainment', 'Rent', 'Bills', 'Shopping', 'Investments', 'Other'.
- `description` (VARCHAR(255), default '')
- `created_at` (DATETIME, default utcnow)

### 3. `budgets`
User monthly budget targets per category.
- `id` (INTEGER, Primary Key, Autoincrement)
- `user_id` (VARCHAR(64), ForeignKey('users.id'), Index)
- `category` (VARCHAR(64), Not Null)
- `allocated_amount` (FLOAT, Not Null)
- `month_year` (VARCHAR(7), Not Null): 'YYYY-MM'

### 4. `goals`
Financial aspirations (e.g. Laptop, Bike, Emergency Fund).
- `id` (INTEGER, Primary Key, Autoincrement)
- `user_id` (VARCHAR(64), ForeignKey('users.id'), Index)
- `name` (VARCHAR(128), Not Null)
- `target_amount` (FLOAT, Not Null)
- `current_amount` (FLOAT, default 0.0)
- `target_date` (VARCHAR(10)): 'YYYY-MM-DD'
- `monthly_contribution` (FLOAT, default 0.0)
- `created_at` (DATETIME, default utcnow)

### 5. `coin_ledger`
Immutable ledger of earned and spent coins. Current balance = SUM(delta).
- `id` (INTEGER, Primary Key, Autoincrement)
- `user_id` (VARCHAR(64), ForeignKey('users.id'), Index)
- `delta` (INTEGER, Not Null): Positive for earnings, negative for expenses/game entry.
- `reason` (VARCHAR(128), Not Null): e.g. 'onboarding_bonus', 'log_expense', 'lesson_complete', 'game_entry', 'game_win'.
- `reference_id` (VARCHAR(64), default ''): e.g. game_session_id or lesson_id for idempotency.
- `created_at` (DATETIME, default utcnow)

### 6. `game_sessions`
Records game attempts, scores, and mistake replays.
- `id` (VARCHAR(64), Primary Key): UUID.
- `user_id` (VARCHAR(64), ForeignKey('users.id'), Index)
- `game_type` (VARCHAR(64), Not Null): 'sip_farm' | 'crash_survivor' | 'scam_detective' | 'budget_bazaar' | 'inflation_island'.
- `score` (INTEGER, default 0)
- `decisions` (TEXT): JSON string of user moves/choices.
- `replay_summary` (TEXT): Comparative feedback from mentor.
- `coins_awarded` (INTEGER, default 0)
- `created_at` (DATETIME, default utcnow)

### 7. `chat_messages`
Chat history for the AI coach mentor.
- `id` (INTEGER, Primary Key, Autoincrement)
- `user_id` (VARCHAR(64), ForeignKey('users.id'), Index)
- `role` (VARCHAR(16), Not Null): 'user' | 'assistant' | 'system'
- `content` (TEXT, Not Null)
- `created_at` (DATETIME, default utcnow)

### 8. `lessons_done`
Tracks completed lessons for idempotency (coins only granted once per lesson).
- `id` (INTEGER, Primary Key, Autoincrement)
- `user_id` (VARCHAR(64), ForeignKey('users.id'), Index)
- `lesson_id` (VARCHAR(64), Not Null)
- `completed_at` (DATETIME, default utcnow)
